Sobre Mim

Sou um desenvolvedor front-end com experiência em criar aplicações web modernas e
eficientes, utilizando, HTML, CSS, JavaScript, jQuery, SASS e LESS, além de aplicar princípios de
UX e UI para entregar interfaces funcionais e atrativas.

Acredito que a melhor forma de crescer como desenvolvedor é através da prática constante e do trabalho em projetos desafiadores. Cada projeto é uma oportunidade de aprender algo novo e aprimorar minhas habilidades.

Busco sempre evoluir não apenas tecnicamente, mas também no desenvolvimento de uma visão mais estratégica, voltada para criar experiências digitais que unam performance, usabilidade e design. Meu objetivo é contribuir para soluções que realmente façam diferença na vida das pessoas

Código Limpo

Design Responsivo

Performance
